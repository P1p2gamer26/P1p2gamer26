### CODEFEST 2026-1

*Sistemas de información & recuperación* — Python · FAISS · HuggingFace

Sistema de **recuperación de información** con búsqueda vectorial multicapa, desarrollado como proyecto de competencia.

- Pipeline con **3 encoders** en cascada (MiniLM → GTE → E5)
- Grafo de conocimiento: **224 101 nodos · 754 876 aristas**
- GUI interactiva con Tkinter · **189 tests**
- Métricas: **F1@3 = 0.499 · NDCG@10 = 0.558**

<details>
<summary>Ver más detalles</summary>

```
Pipeline:
  consulta → glosario bilingüe → MiniLM vectoriza
  → FAISS 200 candidatos [RECALL]
  → calibración min-max → GTE re-puntúa (+0.50)
  → E5 re-puntúa (+1.00) [PRECISIÓN]
  → recorte k_pool=200 → agregación top6
  → post-filtro por fenómeno → 3 documentos
  → 10 fragmentos ≤250 palabras
```

| Encoder | Rol | Params | Ventana |
|---|---|---|---|
| MiniLM | Primario | 118M | 128 |
| GTE | Re-puntuador | 305M | 512 |
| E5 | Re-puntuador | 278M | 512 |

</details>

`Python` `FAISS` `HuggingFace` `scikit-learn` `spaCy` `tkinter`

### Proyecto IA 4

*Machine learning & salud pública* — Python · scikit-learn · Pandas

**Clasificación de conducta suicida** en Bogotá con modelos predictivos sobre datos reales.

- **Random Forest** (100–200 estimadores, max_depth 10–20)
- **SVM** (C [1–10], kernel RBF/Poly) y **MLP** (capas [100,50] / [200,100])
- ~254 000 casos de la **Secretaría Distrital de Salud** (2012–2026)
- Screening temprano: predicción **ideación vs intento**
- EDA completo + experimentos + métricas detalladas

<details>
<summary>Ver más detalles</summary>

- **Dataset**: Datos Abiertos Bogotá — tipos de suicidio
- **Target**: clasificaciondelaconducta (binario)
- **Features**: edad, sexo, ciclo vital, localidad, nivel educativo, factores de riesgo
- **Split**: 80/20 con estratificación
- **Métricas**: accuracy, precision, recall, F1, AUC-ROC, matriz de confusión

</details>

`Python` `scikit-learn` `Pandas` `Matplotlib` `Seaborn` `Jupyter`
