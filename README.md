### 🔎 [CODEFEST 2026](https://github.com/P1p2gamer26/CODEFEST_2026-1)

![Type](https://img.shields.io/badge/🏆_Competition-Python-03787C?style=flat-square)

Sistema de **recuperación de información** con búsqueda vectorial multicapa — proyecto de competencia.

- 🧩 Pipeline con **3 encoders** cascade (MiniLM → GTE → E5)
- 🗺️ Grafo de conocimiento: **224,101 nodos, 754,876 aristas**
- 🖥️ GUI interactiva con Tkinter
- ✅ **189 tests** | **8 páginas** de documentación técnica
- 📊 Métricas: **F1@3 = 0.499 | NDCG@10 = 0.558**
- 🧪 Ground truth propio: 50 consultas, 41 anotadas a mano

<details>
<summary>📦 Ver más detalles</summary>

```
Pipeline:
  consulta → glosario bilingüe → MiniLM vectoriza
  → FAISS 200 candidatos [RECALL]
  → calibración min-max → gte re-puntúa (+0.50)
  → e5 re-puntúa (+1.00) [PRECISIÓN]
  → recorte k_pool=200 → agregación top6
  → post-filtro por fenómeno → 3 documentos
  → 10 fragmentos ≤250 palabras
```

| Encoder | Rol | Params | Ventana |
|---|---|---|---|
| MiniLM | **Primario** | 118M | 128 |
| GTE | Re-puntuador | 305M | 512 |
| E5 | Re-puntuador | 278M | 512 |

</details>

`Python` `FAISS` `HuggingFace` `scikit-learn` `spaCy` `tkinter`

- **Split**: 80/20 con stratificación
- **Métricas**: accuracy, precision, recall, F1, AUC-ROC, matriz de confusión
